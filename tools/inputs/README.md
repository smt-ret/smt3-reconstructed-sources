# inputs/

Supplied by you, from a dump of your own copy (not in the repo):

| File | Required | Produced by |
|---|---|---|
| `smt3hd_main.elf.h` | yes | IDA "Local Types" export of the IL2CPP `main` binary |
| `smt3hd_main.elf.c` | no | Hex-Rays "Export to C" of the same database (`--source`, `--bodies`) |
| `smt3hd_main.elf.map` | no | IDA "Produce MAP file" of the same database (`--map`) |
| `global-metadata.dat` | no | the game's own file; enum values and `#define` constants (`--metadata`) |

Committed, regenerated by the tools beside them:

| File | Built by | Holds |
|---|---|---|
| `stringliteral_map.json` | `build_literal_map.py` | `StringLiteral_<n>` -> text, from the metadata usage tables |
| `array_lengths.json` | `build_array_lengths.py` | struct/field -> element count |
| `il2cpp_arrays.json` | eden `EDEN_IL2CPP_ARRAYS` | array lengths observed on the heap |
| `il2cpp_classes.json` | eden `EDEN_IL2CPP_CLASSES` | class name and namespace per usage slot |

```sh
smt3dump tools/inputs/smt3hd_main.elf.h -o src \
    --source tools/inputs/smt3hd_main.elf.c --metadata tools/inputs/global-metadata.dat \
    --map tools/inputs/smt3hd_main.elf.map --bodies --stats
```

Array counts come from two places: a constant count in a constructor allocation, else a
length observed at runtime. The first wins where both exist.
